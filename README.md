# 日晷设计系统 · Sundial Studio

TypeScript + WebGL2 的高精度日晷设计与三维投影验证系统。输入地点经纬度与墙面
朝向/倾角，自动生成时线、二十四节气线、均时差 8 字线和晷针参数，并在三维场景
里按任意日期/时刻模拟真实太阳投影，可让影子把一年四季自动走一遍。

支持三种晷型，统一在站心 ENU 坐标系（X 东、Y 北、Z 天顶）中用向量几何求解，
**不使用任何"假定正南/竖直"的简化**，歪墙的方位角与倾角如实参与每一步运算。

## 功能对照需求

| 需求 | 实现 |
| --- | --- |
| 经纬度 + 墙面朝向/倾角输入，自动算时线、节气线、晷针长度角度 | `src/core/dialGeometry.ts` |
| 水平式 / 赤道式 / 任意朝向墙面式 | `DialType = horizontal \| equatorial \| wall` |
| 墙面歪斜如实计算 | `wallNormalOf(az, tilt)` 进入全部向量运算，无正南特判 |
| 刻线与天文年历偏差 < 0.5 mm | 审计最大偏差 **0.0000 mm**（见下），单测限值 0.5 mm |
| 均时差可选刻成正午 8 字线 | `buildAnalemma`，UI 复选框开关 |
| 太阳照不到墙的时段不画时线 | `litDeclinationRanges` 逐赤纬判定，不可见线 `points=[]` |
| 晷针有粗细、影子软边、读数边可选 | 鳍板/圆柱网格 + 本影/半影，`leading/trailing/center` |
| 三维场景按任意日期时间投影、全年遍历 | `SceneRenderer` + `AnnualAnimation` |
| 跨纬度城市测试 | 8 个城市（含南半球、赤道、极圈）× 3 晲型 |

## 数学口径

### 太阳位置

采用 NOAA Solar Position Algorithm 截断版：儒略世纪 → 平黄经/平近点角 →
中心差 → 真黄经 → 视黄经（含章动与光行差）→ 赤纬；恒星时走 GMST + 赤经求时角。
赤纬误差 < 0.01°，均时差误差 < 0.2 分钟，ΔT 用分段多项式。折算到 0.3 m 晷面，
线位误差远小于 0.1 mm。

### 晷针（极轴边）

晷针平行地轴。其直线与太阳方向张成的"时角平面"只由时角决定、与赤纬无关，
该平面与晷面的交线就是时线——这是时线不随季节漂移的根本原因。引擎用
`(q × s) × n` 求交线方向（q 极轴、s 太阳方向、n 晷面法向）。

- 水平式：针与盘面夹角 = 纬度绝对值
- 赤道式：盘面平行赤道面，针垂直盘面，时线等分 15°
- 墙面式：针方向按盘面太阳侧定向，副晷针角、针长全部由向量解出

### 影子与读数边

太阳视半径取 0.2667°。半影全宽 `2(r + d·tan0.2667°)`，本影半宽
`max(0, r − d·tan0.2667°)`，d 为针到盘面垂直距离、r 为针半径。
- `center`：理想细针中心线
- `leading`：向日面针尖投影（本影外缘）
- `trailing`：背日面投影

### 受光裁剪

对每条时线扫描全年赤纬，仅当太阳在地平线上 **且** `s·n > 0`（照到墙面太阳侧）
才计入受光区间；无受光赤纬的时线不生成任何刻线点，UI 同步提示省略数量。
`wallLitIntervals` 另对一天做 5 分钟采样 + 二分求根，输出受光 UTC 时段。

## 验证结果

- **单元测试 61 项全部通过**（天文历表、0.5mm 精度、解析公式交叉验证、
  歪墙裁剪、读数边、影子反读、南半球专项）。
- **精度审计**：8 城市 × 3 晲型，时线按盘边角位移、节气线按针尖影子逐点，
  全局最大偏差 **0.0000 mm**，限值 0.5 mm。
- **无头 Chrome 冒烟**：WebGL2 初始化、三晲型/八城市切换、年度动画、
  本影半影显示，零控制台错误。

开发中精度审计曾抓出一个真实缺陷：南半球曾把极轴水平分量错误翻成指南，
导致时线随赤纬漂移（最大偏差上百毫米）。修正为极轴直线恒与地轴共线、
按盘面太阳侧选向后，审计归零，并补了南半球专项回归测试固化该不变量。

## 已知边界

- 太阳位置用 NOAA 低精度公式（米级晷面足够）；若做毫米级大型金属晷且需
  对标 VSOP87/NOAA 高精度版，可在 `astronomy.ts` 内替换实现，接口不变。
- 三维影子用平面平行投影 + 半透明本影层表现软边，未做卷积软阴影；
  半影宽度数值在 UI 与读数计算中均为精确值。
